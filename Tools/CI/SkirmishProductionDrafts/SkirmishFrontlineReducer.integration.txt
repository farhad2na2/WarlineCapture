Implemented pure state/reducer:
- Three distinct stable zone IDs, neutral owners, 500 tickets each.
- Standard/War/LargeWar deadlines 1200/1500/1800 simulation seconds.
- 8 seconds neutralization + 8 capture; neutral begins with one 8-second phase.
- Counts only select presence; more infantry never speeds capture.
- Both sides contest/freeze progress/reset empty grace; owner defense clears opposing work.
- Capturing-faction changes reset partial work; empty grace exactly 10 seconds then 1:1 decay.
- Ownership-after-transitions majority drains opponent 1 ticket/s; 3 owners does not stack.
- Integer persisted progress/grace/ticket fractions, no wall-clock or rendering dependency.
- Combined base/ticket terminal facts resolve before deadline; reciprocal terminals draw.
- Accepted Playing surrender freezes defeat before the next tick; frozen results cannot overwrite.
- Invalid/overflowing input throws before committing partial state; missing authoritative base
  facts fail technically rather than treating default false as original bases destroyed.

Time representation is TimeSpan ticks (100ns) and is not a new gameplay simulation rate.
The native clock adapter must convert authoritative simulation delta using a persisted
sub-tick fractional accumulator. It must not use wall time or round every frame independently.
