# S049 source diagnostic inputs

This route uses S049 Standard/Regular seed 104734 and the existing CH04M05 Armor Break Campaign source. It is source-only: the retained inactive physical capture does not qualify live water or source fit, and the S049 camera motion reference fails strict parity. Native input, visuals, result/return and player acceptance remain unqualified.

Supply a caller-owned, hash-checked bundle and an ExperimentalGroundConfigurationQualification referring to the original direct compiler context. The exact accepted epoch includes metadata projection SHA-256 `c8b588fd4708b1ccc94dd2d2c4d44ffa89a8510adeffc0d73421773fbe5edaec`, captured native metadata `5b1852e889ff1e19e9dd5cfdeedc157d253990dc0d5963c82fe78abbd2cce040`, Armor Break fixed-map capture `6d90b4576abd359dc09eda7cd05108be5212bcf286283e7cec867a56f85ddae3`, rotation reference `4c0c50a546d53e9117aae553ee290db6e0dcc331859c1f4644b65fd0b9bdded3`, and death-input projection `d15289b4888e514145abf44272da142fed9d8a0ed8c5543cc411dfb7b15c2dfe`. These hashes select exact artifacts; they do not make another mission or a fresh capture equivalent.

The compiler-context and qualification descriptors, logical-binding and camera context, fixed-map context, native metadata and their source and authoring pins must remain mutually linked. The caller must supply the captured source root and matching assets; current source pins are also rechecked. Moving a context requires regenerating all hash-linked descriptors with the original owner; do not edit a captured file in place or replace its digest. A focused direct-context relocation control copied all 424 pinned source files to a fresh root, regenerated the context and qualification descriptors, and passed the original context guard; a changed source file was rejected. This does not establish relocation of the complete runtime bundle. The current source graph contains absolute captured-project paths and its three accepted hashes are exact; rewriting those paths changes the graph hash and the qualification rejects it. Complete relocation therefore needs a source-backed graph export and explicit reviewed epoch admission or a verified path-mapping mechanism; a rewritten graph is not accepted as the original artifact.

Build via `run_skirmish_source_simulation.py build` with a supported source build bundle. Run via the same entry point `run`, specifying the caller's S049 bundle, qualification, source/data roots and build receipt. To continue this known diagnostic only, set `WARLINE_S049_PHYSICAL_WATER_DIAGNOSTIC=1` and `WARLINE_S049_CAMERA_DIAGNOSTIC=1`. The latter accepts only the exact recorded motion-reference mismatch and logs it; no tolerance is changed. Either flag forces the resulting receipt to remain diagnostic with validation and readiness false. Without the flags, the original strict gates remain in effect.
