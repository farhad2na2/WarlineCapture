# Premium Gameplay Scene Reference

Date: 2026-05-05

This folder contains a single full-gameplay visual target for the premium 2.5D/3D-look direction.

Unlike the Chapter 1 macro-tile terrain references, this image intentionally includes runtime gameplay objects: buildings, soldiers, vehicles, faction accents, and VFX. Use it as an aspirational gameplay-composition reference, not as a terrain macro tile.

## File

- `WarlineCapture_Premium_2_5D_Gameplay_WithUnits_Target.png`

## Use

- Validate the desired visual quality for the final battle scene.
- Guide runtime entity art direction for buildings, soldiers, APCs, tanks, helicopters, VFX, and faction accents.
- Keep terrain production separate: roads, curbs, pads, blockers, and sockets still belong to macro-tile art plus metadata.

## Rule

Do not import this image as a gameplay map. It is a full-scene target showing how terrain, runtime units, runtime buildings, vehicles, and combat dressing should look together.
