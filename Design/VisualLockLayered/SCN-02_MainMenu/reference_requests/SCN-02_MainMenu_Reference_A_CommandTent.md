# SCN-02 Main Menu Reference A - Command Tent

Use case: ui-mockup
Asset type: landscape mobile game main menu reference mockup, 1672x941.

Primary request:
Create a AAA-quality WarlineCapture main menu reference mockup for a full 3D single-map mobile RTS. This is reference-only; do not produce separated layers yet.

Scene/backdrop:
A forward command tent looking out onto the current WarlineCapture gameplay world, using `Assets/Game/Scenes/Demo.unity` and `Assets/Game/Scenes/Demo2.unity` as the primary references. Visible outside the tent: modular roads and dirt roads, concrete base pads, base walls and barriers, armored vehicles, supply crates, damaged road segments, market/town blocks, airfield or hangar staging, crashed-aircraft debris where useful, and a road-connected 3D operation area. The player should feel like a field commander preparing an attack operation against hostile cells hidden within civilian city districts.

Layout:
- Full-screen command-base frame.
- Top header/resource bar with WARLINE CAPTURE logo, Credits, Supplies, Command, inbox icon, settings gear.
- Left vertical navigation rail with Campaign selected, Operations, Skirmish, Store, Commander, Settings.
- Center three large mode cards: Campaign, Operations, Skirmish.
- Each mode card has 3D operation/base/town art, icon, title, and progress/status strip.
- Right commander panel with COMMANDER, portrait silhouette or scan frame, FIELD COMMANDER, readiness meter, Squad Management locked row, Intel Report locked row.
- Bottom-left comms/status panel showing COMMS ONLINE.
- Bottom-right large gold CTA: DEPLOY OPERATION.

Style:
Dark black/green military panels, weathered metal frames, olive selected states, gold action accents, muted blue command-resource accents, restrained off-white text, readable Oxanium-like typography, realistic 3D depth, premium AAA mobile strategy polish.

Required exact visible labels:
WARLINE CAPTURE, Credits, Supplies, Command, Campaign, Operations, Skirmish, Store, Commander, Settings, COMMANDER, FIELD COMMANDER, READINESS, SQUAD MANAGEMENT, INTEL REPORT, COMMS ONLINE, DEPLOY OPERATION.

Avoid:
No gameplay backdrop that ignores Demo / Demo2, no 2D isometric board, no separate strategic/tactical map split, no old Saga or Quick Custom labels, no fantasy sci-fi neon, no one-color purple/blue palette, no overly rounded card UI, no hidden menu routes, no tiny unreadable text, no baked tutorial instructions, no fourth mode.
