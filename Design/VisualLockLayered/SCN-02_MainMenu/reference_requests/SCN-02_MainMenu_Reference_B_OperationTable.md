# SCN-02 Main Menu Reference B - Operation Table

Use case: ui-mockup
Asset type: landscape mobile game main menu reference mockup, 1672x941.

Primary request:
Create a AAA-quality WarlineCapture main menu reference mockup for a 3D command-base RTS, with the central read focused on a physical operation table and district planning map. This is reference-only; do not produce separated layers yet.

Scene/backdrop:
A command room with a large physical operation table in the foreground, radio equipment, paper intel, district markers, unit miniatures, and operation routes. The table and the visible 3D environment must use `Assets/Game/Scenes/Demo.unity` and `Assets/Game/Scenes/Demo2.unity` as gameplay references: road-connected base compounds, dirt and paved road pieces, base-wall perimeters, barriers, concrete pads, armored vehicles, damaged road segments, town/market blocks, and airfield/hangar staging. The table should imply the same 3D operation map that missions launch into, not a separate strategic board game.

Layout:
- Full-screen military command UI shell.
- Top bar: WARLINE CAPTURE logo, Credits, Supplies, Command, inbox icon, settings gear.
- Left nav: Campaign selected, Operations, Skirmish, Store, Commander, Settings.
- Center mode cards sit above or slightly over the operation table: Campaign, Operations, Skirmish.
- Campaign card shows a mission district/town entry image.
- Operations card shows district stabilization/intel network imagery.
- Skirmish card shows configurable battlefield staging imagery.
- Right commander panel: portrait silhouette, FIELD COMMANDER, readiness meter, locked Squad Management and Intel Report rows.
- Bottom-left COMMS ONLINE status.
- Bottom-right DEPLOY OPERATION gold CTA.

Style:
Dark command table lighting, black/olive metal UI, thin bevels, worn edges, restrained gold CTA, muted blue command overlays, soft cinematic 3D lighting, readable mobile-first typography.

Required exact visible labels:
WARLINE CAPTURE, Credits, Supplies, Command, Campaign, Operations, Skirmish, Store, Commander, Settings, COMMANDER, FIELD COMMANDER, READINESS, SQUAD MANAGEMENT, INTEL REPORT, COMMS ONLINE, DEPLOY OPERATION.

Avoid:
No gameplay art unrelated to Demo / Demo2, no old 2.5D isometric gameplay art, no macro-tile look, no Saga, no Quick Custom, no globe/world-war fantasy, no casino/store-first look, no decorative UI that hides real buttons, no oversized hero text.
