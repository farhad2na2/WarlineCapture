## Airport pads from a layout dump (airport-from-dump, missions/airport-from-dump)
`Tools/Missions/airport_sites_to_pads.py --dump <dump.json> --draft <draft.json> [--write|--out P]` is an alternative to `--sites` (exclusive). It uses the dump's `kind=="airport"` candidates (native IsPlacementValid + the starting-placement predicates, already inside logical playable bounds), drops candidates on non-level ground, then the same per-side nearest / non-overlapping selection. Errors (exit 1, nothing invented): no Airport definition in the session (`missingKinds` contains airport, or the dump `definitions` list has none), definition not scanned, no airport candidate, catalog mismatch. `candidatesTruncated` is flagged in the report.
Harness (additive): `LayoutDump.missingKinds` + a warning + `missingKinds=` in the completion marker, so a requested kind with no configured definition is explicit instead of a silent empty scan.
