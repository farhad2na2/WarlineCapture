# WarlineCapture Generative Cinematic QA

Use this checklist for each AI-generated concept-cinematic clip and for assembled trailer drafts.

## Required Files

- Provider manifest with job ids, provider, model, prompt id, status, output path, and timestamps.
- Downloaded MP4 for each completed clip.
- QA report generated by `Tools/Marketing/generate_concept_video_jobs.py`.
- Human review notes before public use.

## Automated Checks

- Each clip file exists.
- Each completed clip opens in OpenCV.
- Each completed clip has nonzero frame count.
- Each completed clip is at the requested resolution or is flagged for resize.
- Each completed clip has nonblank sampled frames.
- Prompt package and generated manifests contain no unapproved economy or monetization terms except the internal blocked-term rule.
- No shot uses WarlineCapture UI screenshots or visual-lock target screens as direct video source frames.

## Human Review Checks

- The clip reads as concept cinematic, not real gameplay capture.
- Tactical RTS identity is clear: squads, command, city, district recovery, or strategic planning.
- The clip does not imply mechanics not in the design docs.
- Monetization is not shown as victory, mission completion, star purchase, or district metric purchase.
- Operation recovery is shown as action and consequence, not a paid direct stat grant.
- No readable fake UI text, fake resource labels, or fake store language appears in the footage.
- Motion is stable enough for a marketing draft: no severe warping, unwanted extra limbs, flickering vehicles, or unreadable action.
- Visual tone is premium stylized 3D, not generic stock sci-fi, horror, or live-action military footage.

## Approval States

| State | Meaning |
|---|---|
| `Rejected` | Violates design, economy, visual, or quality rules. Do not assemble. |
| `RevisePrompt` | Concept is right but prompt needs tighter subject, camera, or negative constraints. |
| `UsableDraft` | Acceptable for internal rough trailer assembly. |
| `ApprovedForValidation` | Ready for user review as a marketing concept draft. |
| `ApprovedForPublishPrep` | Passed legal, brand, platform, and final production review. |
