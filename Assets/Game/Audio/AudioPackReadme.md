# WarlineCapture Generated Audio Pack

Generated by `Tools/generate_warlinecapture_audio.py`.

This pack contains deterministic WAV assets for the first vertical slice listed in `Design/Audio_Design_Guidelines.md`. The clips are implementation-ready prototype assets: suitable for wiring, testing, and early play feel. Final AAA release audio should replace or sweeten these with dedicated sound-design masters while preserving filenames/event ids.

Current config-driven event assignments are generated by `Tools/Audio/generate_placeholder_audio.py`.

- Catalog: `Assets/Game/Audio/Config/audio_event_catalog_v0_1.json`
- Manifest: `Assets/Game/Audio/GeneratedSource/audio_placeholder_manifest_v0_1.json`
- Scope: data-only asset/event assignment; no runtime playback implementation.

## Menu and match music

The menu and match loop assets are AI-generated production candidates, not the former
deterministic placeholders:

- `Music.Menu.Loop` uses `Music/music_menu_loop_01.wav`.
- `Music.Match.CalmLoop` uses `Music/music_match_calm_loop_01.wav`.
- `Music.Match.CombatLoop` uses `Music/music_match_combat_loop_01.wav`.

They were generated with ElevenLabs `eleven_text_to_sound_v2` through
`Tools/Audio/generate_elevenlabs_sfx.py`, normalized for long-form music, and selected
by the repository audio QA. `Music/menu_match_music_generation_manifest.json` records
the exact prompts, candidate metrics, and selections. Runtime playback remains local;
the game does not call ElevenLabs.

Shipping rights remain subject to the commercial-use terms of the ElevenLabs account
used for generation and must be verified during release clearance.
