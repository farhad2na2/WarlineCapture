# SCN-02 Main Menu Reference C - Forward Base Hangar

Use case: ui-mockup
Asset type: landscape mobile game main menu reference mockup, 1672x941.

Primary request:
Create a AAA-quality WarlineCapture main menu reference mockup emphasizing a 3D forward base hangar and live operation staging. This is reference-only; do not produce separated layers yet.

Scene/backdrop:
A forward operating hangar or command shelter based on `Assets/Game/Scenes/Demo.unity` and especially `Assets/Game/Scenes/Demo2.unity`. Use the Demo / Demo2 gameplay language: concrete base pads, base walls, broken wall pieces, dirt and paved roads, damaged road sections, armored cars/APCs, plane-crash debris, airfield/hangar staging, supply crates, road barriers, and town/market blocks beyond the base perimeter. The scene should feel like the commander is preparing units before deploying into one large 3D city map.

Layout:
- Top header/resource bar: WARLINE CAPTURE logo, Credits, Supplies, Command, inbox icon, settings gear.
- Left vertical nav rail: Campaign selected, Operations, Skirmish, Store, Commander, Settings.
- Center mode cards: Campaign, Operations, Skirmish. Cards should be large, readable, and visually distinct.
- Right commander panel: COMMANDER, portrait/scan frame, FIELD COMMANDER, READINESS, locked Squad Management, locked Intel Report.
- Bottom-left COMMS ONLINE panel.
- Bottom-right DEPLOY OPERATION CTA as the strongest action.

Style:
Premium military RTS UI, grounded 3D base environment, black/olive panels, weathered steel, gold CTA, small muted blue data accents, clear mobile hierarchy, no decorative clutter over buttons.

Required exact visible labels:
WARLINE CAPTURE, Credits, Supplies, Command, Campaign, Operations, Skirmish, Store, Commander, Settings, COMMANDER, FIELD COMMANDER, READINESS, SQUAD MANAGEMENT, INTEL REPORT, COMMS ONLINE, DEPLOY OPERATION.

Avoid:
No gameplay backdrop that conflicts with Demo / Demo2, no old teal/cyan-dominant UI, no 2D/isometric battlefield art, no Saga Campaign, no Quick Custom Game, no tactical/strategic split map, no hidden Settings route, no text clipped inside buttons, no comic/cartoon style.
