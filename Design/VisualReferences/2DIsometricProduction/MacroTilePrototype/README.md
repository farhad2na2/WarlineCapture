# Macro Tile Prototype Outputs

Date: 2026-05-05

This folder is reserved for the selected terrain direction: large authored 2D isometric macro tiles plus metadata.

- `Chapter01_2_5DReferences/`
  - Five Chapter 1 visual targets for the 2.5D macro-tile direction.
  - These are reference images for mission/map identity, not final imported runtime tiles.

- `PremiumGameplayScene/`
  - One full-scene premium gameplay reference with buildings, soldiers, vehicles, and VFX.
  - This is an aspirational gameplay-composition target, not a terrain macro tile.

- `FictionalGulfStyle/`
  - One custom fictional Gulf-region premium battle reference with coastal city, air/naval pressure, buildings, soldiers, and vehicles.

## Rule

Do not add tiny road-tile, independent road-chunk, generated road-overlay, or procedural final-art experiments here.

Macro tiles are terrain presentation. Gameplay truth is metadata.
