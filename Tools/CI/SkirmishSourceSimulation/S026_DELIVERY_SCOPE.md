# Prospective S026 CLI delivery

This candidate adds the normal S026 typed-ground backend for Regular difficulty, seed 104755, and Standard, War and LargeWar sizes. S002 retains its separate 12-template backend; S026 uses its qualified 16-template domain. Profile availability requires final publication review.

Captured mission inputs remain external data. Supply explicit current source, runtime data and metadata-origin roots, with exact descriptors for initialization, static map, navigation, roads, templates, camera, logical binding, metadata, mechanical death inputs and command text. Recreate path-bound descriptors through their qualified producers when relocating inputs; copying an old locator manifest does not qualify a new location. The normal tool owns admission, build, preflight, worker execution and receipts.

A bounded prefix reports execution through a requested tick cap; it is not a mission Victory. A natural Defeat may complete execution while failing mission validation. Missing or contradictory receipts, process failure and timeout must remain failures. The sequential batch wrapper preserves each job's actual normal command and receipts; it does not add mission admission or run jobs concurrently. The trace analyzer is passive and cannot prove unsupported reservation conservation.

Prior private normal S026 Standard, War and LargeWar runs reached natural Victory. A fresh combined clean-public build and normal S002/S026 regression remain required before publishing this assembled payload. Native visual/input, result-and-return, player/device and readiness acceptance are separate.

Parent-index changes, private budget/shadow diagnostics, S050 probes and unrelated UI work are excluded. S050 placement replay/discovery is a separate future data-parameterized tool contract: preserve original owner extraction, exact captured source inputs and explicit logical QA; changing pad JSON should require neither Unity capture nor a C# rebuild. That tool is not included in this payload.
