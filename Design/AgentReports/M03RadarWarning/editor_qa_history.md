## Findings fixed during QA

- A genuine atomic profile-write failure previously left Victory unavailable without a recovery surface. The result now explains the failure and exposes Retry Save through the original settlement owner; the normal debrief/Victory sequence resumes only after persistence succeeds.
- Retry originally left M3 buildings behind because M3 has no mandatory build objective. Cleanup now has an attempt-owned defense path and delegates full removal to the existing building owner.
- Authored map-building IDs and runtime-building IDs use separate sequences. The runtime ownership baseline now excludes authored map buildings; the cleanup query also preserves authored buildings.
- Result UI no longer recreates itself over the field guide. Closing the guide restores the same result.
- ARIA's M3 card has enough space for all twelve lessons in both locales and sizes, and restores the previous M1 geometry when leaving M3. M1-only step numbering no longer affects M3.
- Persian guide navigation/search, mixed-script font selection and result reward overflow were corrected using actual text bounds and visible captures.
- Old two-mission catalog fixtures now assert the ordered M1/M2/M3 identities and M2-clear → M3 availability; the 23-suite behavior audit passed before the later command/presentation refinements.

- First Persian B01 comic capture had no missing glyphs or truncation, but the full two-line text required 126.73 px inside a 112 px authored box. Authored comic captions now use bounded autosizing. Comics-04/05 verified the full normal-size matrix.
- Live comic locale and aspect refresh use existing narrative presentation owners and preserve progression. Narrative configs now bind current/next Addressable sprites; Comics-05 accepted the current/next residency and final release checks.
