# WarlineCapture Generated Audio Pack

Generated by `Tools/generate_warlinecapture_audio.py`.

This pack contains deterministic WAV assets for the first vertical slice listed in `Design/Audio_Design_Guidelines.md`. The clips are implementation-ready prototype assets: suitable for wiring, testing, and early play feel. Final AAA release audio should replace or sweeten these with dedicated sound-design masters while preserving filenames/event ids.

Current config-driven event assignments are generated by `Tools/Audio/generate_placeholder_audio.py`.

- Catalog: `Assets/Game/Audio/Config/audio_event_catalog_v0_1.json`
- Manifest: `Assets/Game/Audio/GeneratedSource/audio_placeholder_manifest_v0_1.json`
- Scope: data-only asset/event assignment; no runtime playback implementation.

## Menu and match music

The menu and match loop assets are full stereo compositions, not event-style
sound-generation candidates, sustained drones, or the former short placeholders:

- `Music.Menu.Loop` uses `Music/music_menu_loop_01.wav`.
- `Music.Match.CalmLoop` uses `Music/music_match_calm_loop_01.wav`.
- `Music.Match.CombatLoop` uses `Music/music_match_combat_loop_01.wav`.

They are arranged reproducibly by `Tools/Audio/generate_background_music.py` from
GarageBand performances of military brass, marching snare, orchestral strings, darbuka,
Persian tar, and oud. Brass and marching cadence define the score; the Middle Eastern
instruments provide restrained regional color. The three arrangements have melody,
meter, rhythmic motion, and multi-section musical form; they do not use the earlier
oscillator-based sustained beds. The menu theme is approximately 71.1 seconds, the calm
Match loop is approximately 60.6 seconds, and the combat loop is 57.6 seconds.
`Music/menu_match_music_generation_manifest.json` records every source performance,
arrangement layer, license reference, and measured output.

Apple permits its GarageBand loop content to be used royalty-free in original music
compositions and audio projects, but does not permit redistribution of individual source
loops. Only the rendered WarlineCapture arrangements are stored in this project. See
<https://support.apple.com/102034>.

Regeneration requires Python 3 with NumPy, FFmpeg, and the GarageBand sound library.
The rendered masters contain no generated-service output and do not redistribute the
individual GarageBand source performances.
