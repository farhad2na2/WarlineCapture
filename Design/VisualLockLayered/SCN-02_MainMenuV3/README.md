## Direction

- Keep the Main Menu V3 composition: Campaign primary, Operations and Skirmish smaller, selected commander center, ARIA right, Store and Armory bottom.
- Replace ornate gold-frame visual language with sharper, more solid modern UI.
- Use larger tap targets, sharp rectangular panels, strong drop shadows, and bright category colors.
- Use true square rectangular corners where possible. Avoid rounded corners, diagonal chamfers, and decorative notches on primary panels.
- Store and Armory sit in a bottom-docked footer shelf with their lower edges flush to the screen bottom.
- Gold is only a small accent, not the main border system.
- Header resources are Credits and Command only.
- Avoid diamonds, gems, water, sea, coast, naval backgrounds, and old thin gold HUD borders.
