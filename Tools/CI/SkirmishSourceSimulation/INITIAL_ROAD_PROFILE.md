# Fresh Match initial roads

Ordinary source initialization owns the original `RoadNetworkCompositionSystemHelper` and executes the complete current `RoadGridProjectionSystem.SyncRoadCellsToEcs` and `ClearRoadBuffers` bodies on the same canonical grid, after authored navigation import and before buildings, opening actors or path use. The generator preserves the complete network class; its only binding is a file-local alias to the already qualified actual Unity quaternion type. The grid queries and numeric projection helpers come from current native source, not frozen copies.

Admission is deliberately finite: the selected pinned Match scene must reference the actual road-build and runtime-city config assets; their script identities and current native scalar getters must match; city generation must be disabled by actual CityCount zero; and the actual fresh network must have no tiles/strokes/edges/autobahn cells and its original initial stroke epoch. Explicit saved-road/restore inputs are unsupported. Input/config drift, nonempty or changed network state, incomplete buffers and another grid reject before projection writes. Each ordinary owner tick verifies the retained empty network before path use. The world owns the network/projection lifetime.

No road footprint callback returns guessed bounds or success: that consumed domain throws. Nonempty road generation, commands, restore and later mutation remain unsupported. This initial managed registry is distinct from physical Campaign roads and the authored placement surface mask. Empty ECS road buffers do not claim that the map has no physical roads.

The run emits `initial-road-before-world.json`, `initial-road-sync.json`, `initial-road-after-run.json` and the `initial_road_projection` result field. They contain actual source/config pins, canonical grid identity, three full-buffer hashes and a structured owner stage suitable for the smoke runner. Source inputs are verified before writes and again before a result qualifies. Ordinary CLI commands and the raw navigation fallback are unchanged.

Focused source regeneration controls run with `SKIRMISH_SOURCE_REPO=/absolute/current/native/source python3 -B Tools/CI/tests/test_skirmish_initial_roads.py -v`. They check complete original bodies, exact raw-byte pins, current getter regeneration, query/population admission, source drift and portable line endings. The separate qualification packet records the actual tiny-grid original-owner controls and ordinary five-tick equality; neither is a full native mission/readiness claim.
