## Direction

- Use exactly `Credits` and `Command` as persistent currencies.
- Never sell or grant match-only Materials, Oil, or Fuel.
- Use large left categories, large deterministic offer cards, a selected-offer detail panel, and one global purchase action.
- The selected target state is `Recon Starter Pack` with exact contents and duplicate handling shown.
- Attach the footer to the bottom with `Back`, eligibility information, and `Purchase $4.99`.
- Use sharp rectangular V3 panels, solid colorful product states, and large mobile controls.
- Avoid gems, random loot-box language, repeated buy buttons, rounded or chamfered frames, and old thin blue sci-fi styling.
