# Fixed-map preflight parity controls

The controls compare the original read followed by navigation decode with the combined request-local implementation for twelve malformed binding, context and missing-file cases. They compare exact exception types and messages and allocate no World. Supply a qualified source build receipt, source CLI and project root, Mono config, actual binding and its SHA-256, a fresh missing absolute path, and a fresh output directory. The runner verifies build input pins before and after compilation and execution.

A captured binding and its referenced inputs are external fixtures; no machine-specific fixture is bundled. This test does not demonstrate concurrent mutation between reads, a full mission, or native/player readiness.
